# Audit Log Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an opt-in `audit` callback on `createAdminHandler` that fires after successful create/update/delete with a redacted, typed `AuditEvent` so apps can record which admin changed which row.

**Architecture:** A new `src/lib/server/audit.ts` owns redaction, diffs, snapshot reads, and best-effort emission. `handler.ts` calls it only after a successful write, and only reads `before` when `audit` is configured. Prisma/Drizzle adapters are unchanged.

**Tech Stack:** TypeScript, Vitest (100% coverage on `src/lib/**`), existing Prisma mock + SQLite integration harness.

## Global Constraints

- Package manager is bun; tests via `bunx vitest run <file>` after `bun run test:gen` if the Prisma test client is missing.
- 100% coverage on `src/lib/**` — no `/* v8 ignore */`, no uncovered default-throw branches.
- Reuse `isSensitiveFieldName` from `parser.ts`; do not invent a second sensitive-name heuristic.
- No extra `getRecord` when `audit` is omitted (characterization call counts must stay stable).
- `audit` that throws must not fail the 303; log with `console.error('[sveltekit-admin] audit callback failed:', err)`.
- New public capability → MINOR changeset; one `.changeset/audit-log.md`.
- Imports stay at the top of the file (no inline imports).
- Discriminated `AuditEvent` union; handler/build helpers use `if` on `action` rather than an unreachable `default: never` throw.

- [ ] **Step 3: Implement `src/lib/server/audit.ts`**

Exact public shapes (internal runtime, types also re-exported later):

```ts
export type AuditAction = 'create' | 'update' | 'delete';

export type AuditEvent =
  | {
      event: any;
      at: Date;
      action: 'create';
      model: string;
      id: string | number;
      values: Record<string, unknown>;
      after: Record<string, unknown>;
      m2m?: Record<string, Array<string | number>>;
    }
  | {
      event: any;
      at: Date;
      action: 'update';
      model: string;
      id: string | number;
      values: Record<string, unknown>;
      before: Record<string, unknown> | null;
      after: Record<string, unknown>;
      changes: Record<string, { from: unknown; to: unknown }>;
      m2m?: Record<string, Array<string | number>>;
    }
  | {
      event: any;
      at: Date;
      action: 'delete';
      model: string;
      id: string | number;
      before: Record<string, unknown> | null;
    };
```

`redactForAudit`: iterate `model.fields`; skip `relation`, `isList`, `isSensitiveFieldName(name)`, `hidden.has(name)`; copy only keys present on the record.

`diffRecords`: union of keys; skip equal via `auditValuesEqual`.

`buildAuditEvent` input:

```ts
{
  event: any;
  at?: Date;
  action: AuditAction;
  model: Model;
  id: string | number;
  hidden: ReadonlySet<string>;
  values?: Record<string, unknown>;
  m2m?: Record<string, { targetPkField: string; ids: Array<string | number> }>;
  before?: Record<string, unknown> | null;
  after?: Record<string, unknown>;
}
```

Create: redact `values` and `after`. Update: `afterRaw = { ...(before ?? {}), ...(after ?? {}) }` then redact; `changes = before ? diffRecords(redact(before), redact(afterRaw)) : {}`. Delete: redact `before` if non-null. Compact m2m to `{ [field]: ids }` or omit.

`readAuditSnapshot(getRecord, model, id)`: try/catch → `null`.

`emitAudit`: if `!audit` return; try `await audit(entry)` catch `console.error('[sveltekit-admin] audit callback failed:', e)`.

- [ ] **Step 3: Wire handler**

On `AdminHandlerConfig`, add `audit` with JSDoc matching the `logout` tone (bring-your-own sink, POST mutations only, best-effort, redaction, `event.locals` for the actor).

Destructure `audit` next to `logout`.

After successful `deleteRecord`:

```ts
if (action === 'delete' && route.id) {
  const before = audit
    ? await readAuditSnapshot(
        (m, id) => adapter.data.getRecord(m, id),
        model,
        coerceId(route.id, model)
      )
    : null;
  await adapter.data.deleteRecord(model, route.id);
  await emitAudit(
    audit,
    audit
      ? buildAuditEvent({
          event,
          action: 'delete',
          model,
          id: coerceId(route.id, model),
          hidden: hiddenFieldsOf(model),
          before
        })
      : undefined as never
  );
```

Cleaner: only call `emitAudit` when `audit` is set, so TypeScript does not need `undefined as never`. `emitAudit(undefined, entry)` is still covered by Task 1 unit tests.

```ts
if (action === 'delete' && route.id) {
  const before = audit
    ? await readAuditSnapshot((m, id) => adapter.data.getRecord(m, id), model, coerceId(route.id, model))
    : null;
  await adapter.data.deleteRecord(model, route.id);
  if (audit) {
    await emitAudit(
      audit,
      buildAuditEvent({
        event,
        action: 'delete',
        model,
        id: coerceId(route.id, model),
        hidden: hiddenFieldsOf(model),
        before
      })
    );
  }
  return redirectToList(route.model);
}
```

Create: capture `const created = await adapter.data.createRecord(...)`. `id = created[primaryKeyOf(model)] as string | number`. Emit create with `values: data`, `after: created`, `m2m: m2mInput`.

Update (only `route.id`): snapshot `before` if `audit`, then `const updated = await adapter.data.updateRecord(...)`, then emit with `values: data`, `before`, `after: updated`, `m2m: m2mInput`.

Do not emit on the historical “update without id still 303” path.
